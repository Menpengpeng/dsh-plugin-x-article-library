## 压缩方式

原始截图分别为 1920×1032（824 KB）和 1646×1030（601 KB）。处理为：

1. 宽度超过 1760px 的等比缩到 1760（GitHub README 正文栏约 880px，2x 屏幕下 1760 足够清晰）；
2. 转 256 色调色板（UI 截图颜色数有限，观感几乎无损）；
3. PNG `optimize=True` 重新编码。

两张合计从 1.4 MB 降到 479 KB。文字在 GitHub 上的实际显示宽度下仍然清晰。

## 更新截图时

替换同名文件后重新压缩即可：

```powershell
python tmp/optimize-shots.py   # 输出到 tmp/shots-out/，确认清晰后再覆盖
```

注意保持内容干净：不要带报错条、下载失败条目或未打码的私人信息。
